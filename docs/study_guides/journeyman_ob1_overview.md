# 2023 Journeyman Open Book Exam #1

## Exam Profile

- 25 questions
- 60-minute time limit
- Average pace: 2 minutes 24 seconds per question
- Open-book NEC study practice
- Self-grade: correct answers divided by total questions

## Topics Covered

- Multiwire branch-circuit disconnects
- Grounding and bonding
- Branch-circuit and lighting-load calculations
- NM cable protection near framing
- GFCI requirements
- Switchboard and switchgear conductor rules
- Equipment access and marking
- Temporary wiring
- Appliance and laundry receptacles
- Pool motor protection
- Air-conditioning disconnects

## Study Method

Use the answer key to locate and highlight the cited NEC section in the code book. Keep the question wording and answer choices unchanged; explanations and supplied code provisions are stored separately in the quiz bank.

## Verified References

The question bank contains the verified answer and reference for all 25 questions. Supplied source provisions are displayed after answering under `CODE PROVISION`, with the lesson under `WHAT THE CODE SAYS`.

## Timing Note

The 60-minute limit is the source exam's overall clock. The practice app may also show an average pacing timer, but that pacing timer does not replace the overall clock.
